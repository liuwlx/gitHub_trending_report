🤖 AI 编程工具正在从“对话框”变成完整运行环境

ego-lite 提供可共享登录态的浏览器执行环境，t3code 把编码 Agent 包装成 Web 工作台，Instatic 把 Agent 能力嵌进 CMS，open-code-review 则把确定性规则和 LLM Agent 接到审查流程。共同变化不是多几个 Prompt，而是 Agent 开始拥有浏览器、会话、状态和可恢复工作流。

🏠 本地优先和自托管重新成为产品卖点

bitchat 强调断网通信，superfile 把文件管理留在终端，Instatic 用单个 Bun 进程承载编辑与发布，Chat2DB Community 桌面强调本地离线。云服务没退场，开发者只是更认真地问：数据和权限到底归谁管。

🔐 权限、许可证和性能主张需要慢看
