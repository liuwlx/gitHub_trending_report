🔍 今日洞察
🤖 Agent 工具从“会聊天”走向“有规矩地干活”

reverse-skill、Reasonix、Agent-Reach 和 free-claude-code 分别处理任务路由、终端编码、外部平台接入和模型访问。共同点不是再造聊天框，而是把权限、工具、上下文与执行流程真正接起来。

📄 先判断要不要 OCR，比所有 PDF 一锅端更实用

pdf-inspector 先分类 PDF，再对可直接读取的页面提取带位置的文本并转成 Markdown。贵活留给 OCR，能直接解析的别绕远路。

⚙️ 本地推理开始为具体模型和硬件深度特化

ds4 不做万能 GGUF runner，而是围绕少数模型、Metal/CUDA/ROCm、KV 状态和 SSD 专家加载一起优化。通用性少一点，工程深度多一点。

📚 教程长期霸榜，但不等于软件架构样本

两套 Microsoft AI 课程和 system-design-primer 仍有巨大传播力。本日源码深挖把名额留给具有入口、运行时和可追踪执行链路的项目。
